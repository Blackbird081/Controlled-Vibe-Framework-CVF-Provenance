## Canonical Residual Boundary

The minimum supported residual is:

`qualified evidence or diagnostic decision reference`

`-> non-authoritative Learning Candidate`

`-> Local reviewed conversion, rejection or defer decision`

`-> governed Work Order with stable candidate binding`

`-> existing owner-specific assurance`

`-> CADP and exact-version admission/eligibility lineage`

This is a handoff problem across existing owners, not a missing general
capability-evolution subsystem.

The candidate need preserve only a stable reference to its qualified decision
and evidence basis plus its own proposal identity/state. The reviewed
conversion owns whether a Work Order is created. The Work Order owns the actual
mutation contract. Downstream owners select assurance routing and exact
version after an actual owner/artifact exists.
