## Recommended Tranche

Recommended tranche ID: `EKA-R1`.

Recommended name: `External Knowledge Intake Routing Guard T1`.

Bounded objective: add one range-aware governance checker that requires changed
governed external-intake artifacts to identify their input type, cite the
External Knowledge Absorption Chain Map, and route to the matching existing
local-view guard or record a bounded non-applicability reason.

The checker should compose existing CVF semantics rather than duplicate them:

1. Chain-map citation and input-type routing.
2. Existing Required Absorption Table guard for returned external-agent output.
3. Existing blind-spot and legacy-coverage evidence for legacy-adjacent work.
4. Existing corpus registry/generated-aggregate discipline for corpus claims.
5. Existing source-verification and autorun gates before implementation.

## Why This Is Higher Value Than Delta-T4 Now

EKA-R1 acts before future absorption and implementation decisions, so one
bounded machine guard improves many later lanes. Delta-T4 deepens one execution
lane but immediately opens higher-risk mutation semantics. EKA-R1 therefore
offers broader governance leverage with lower irreversible risk and makes
future legacy/external scans more reliable.
