## Roadmap Decision

Decision: BUILD_AS_WORKFLOW_CHAIN_AFTER_SOURCE_VERIFICATION

CVF should not absorb the legacy material as independent modules. The correct
target is a governed memory/learning workflow chain:

Execution evidence -> source/trace receipts -> task/context packaging ->
knowledge routing/fusion -> governed memory candidate -> truth/evaluation ->
reputation/trust/risk signal -> learning proposal -> simulation/failure/audit
validation -> governance approval -> bounded policy/context/memory update ->
rollback/decay/dispute path.

The roadmap is system-level, but runtime work is blocked until current source
owners, field names, schemas, commands, and tests are source-verified.

## Non-Negotiable Boundaries

- Memory is not truth.
- Capture is observation, not permission.
- Learning proposes; governance approves.
- No raw memory or raw retrieval injection.
- No agent/provider/MCP direct memory path.
- No LLM call without governed context fusion for retrieval-backed execution.
- No memory write without sync/lifecycle/provenance controls.
- No audit or planner memory loop may mutate live policy directly.
- No parallel runtime from Hermes, Hugging Face, deepagents, MemPalace,
  Tolaria, cortex-hub, or Agent Harnesses.
- No public claim until a public-safe summary exists in the public repository.
