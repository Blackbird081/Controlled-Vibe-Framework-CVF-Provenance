## Purpose

Define the next governed path from MinerU absorption and adapter-contract
vocabulary toward practical CVF document extraction productization. R11 exists
because MSEA-R4 through MSEA-R10 have absorbed the upstream repository,
document-layer evidence, receipt vocabulary, residual corpus coverage,
application route readiness, and adapter contract draft, but none of those
artifacts authorizes runtime implementation.

The immediate value is a source-verified route-selection tranche that decides
which productization lane, if any, should be opened first.
