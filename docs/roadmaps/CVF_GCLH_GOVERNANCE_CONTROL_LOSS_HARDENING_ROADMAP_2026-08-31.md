## Authorization / Decision

The operator authorized CVF Core learning and foundation hardening from the
governance control-loss record and its independent downstream review. Core
learning must complete before any refresh or application to the named
workspace/project.

Current decision: GCLH-T1 design is accepted bounded. GCLH-T2 remains held
until a fresh protected-path work order names exact owner changes, hostile
tests, rollback evidence, and Core Guard Self-Protection authorization. Schema
capability, downstream refresh, public-sync, runtime, provider/live,
deployment, and production remain parked.

## Purpose

Convert the observed control-loss sequence into the smallest non-duplicative
CVF foundation upgrade. Preserve the seven-phase authorization chain while
left-shifting capability discovery, semantic adversarial evidence, repair
regression detection, review-cost escalation, control projection freshness,
and hash identity precision.

The governing distinction is:

`phase authorization containment != phase-input quality and convergence`

## Scope

In scope:

- exactly two operator-named downstream learning artifacts;
- comparison of their proposed controls with current CVF owners;
- an adversarial replay route through SCEC and review-cost controls;
- design candidates for capability audit, semantic preflight, immutable
  constraints, hash byte-domain, and downstream projection freshness;
- separate disposition of schema capability changes and orchestration
  observability guidance;
- a held downstream refresh/application lane after Core closure.

## Non-Goals

- No direct import of downstream prose as CVF authority.
- No claim that multi-agent or single-agent multi-role operation is inherently
  unsafe.
- No new repair-stop framework parallel to SCEC or the review-cost standard.
- No automatic inspection of private reasoning or semantic-truth scoring.
- No update to the sibling workspace/project during GCLH-T0 through GCLH-T3.
- No runtime, provider/live, credentials, network write, public-sync, push,
  deployment, release, or production authority.

## Epistemic Process Block

### Expected Result / Prediction

Most proposed controls should enrich existing SCEC, review-cost, file-size,
finding-learning, and propagation owners; only a smaller residual should need
new contract design.

### Evidence Comparison

The source record proposed ten controls. Current Core inspection found direct
or partial owners for L2-L4 and L7-L10, while L1, L5, L6, L11, and L12 retain
material design gaps. The review-cost and SCEC controls are stronger than the
downstream carrier rule used during the incident.

### Contradiction Or Gap Disposition

The prediction is supported with a residual gap. GCLH therefore enriches
existing owners first and parks schema changes separately instead of creating
one broad new governance framework.

### Claim Update

The T0 author claim is bounded owner reconciliation pending reviewer evidence
reconstruction, not institutionalized learning or implementation readiness.
