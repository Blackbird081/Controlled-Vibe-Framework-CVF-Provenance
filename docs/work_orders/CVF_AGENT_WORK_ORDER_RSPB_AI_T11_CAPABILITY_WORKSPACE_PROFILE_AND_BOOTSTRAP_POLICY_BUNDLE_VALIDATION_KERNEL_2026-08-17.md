## Functional Contract

Export a versioned input/result API and
`evaluateCapabilityWorkspaceBootstrapPolicyBundle(input: unknown)`.

The input must contain only:

- `schemaVersion`, `profile`, `bootstrapPolicy`, `requestedProfileId`,
  `observedPlatform`, `riskLevel`, and `now`;
- one caller-supplied profile whose T7 projection contains `profileId`,
  `platforms`, `shellPreference`, `networkMode`, `installPreference`,
  `scanTtlSeconds`, `privilegePolicy`, `pathDiscovery`,
  `allowedDestinations`, and `notes`;
- T11-owned bounded `writableBoundaries` and `credentialBindings` fields on
  that profile; bindings are reference identifiers only, never raw values;
- one bootstrap policy discriminated by the selected profile/network posture.

The evaluator must call current `evaluateCapabilityPreflightProfilePolicy`
with a one-profile catalog and bind its immutable selected result exactly. It
must not reimplement or weaken T7.

Every bootstrap policy must have a safe `policyId` exactly
`capability-bootstrap.<profileId>`, `defaultDecision: 'BLOCK'`,
`requireIntegrity: true`, and integer
`maxRepairRoundsWithoutNewEvidence` from 1 through 3.

Variant invariants:

- `OFFLINE`: `networkDefault: 'DENY'`, `allowNetwork: false`,
  `allowVerifiedLocalArtifact: true`; T7 offline restrictions remain binding.
- `RESTRICTED`: `networkDefault: 'DENY'`,
  `requireDestinationAllowlist: true`, `allowOfflineArtifacts: true`.
- `NORMAL`: only a `win32`-compatible profile may use the local-install policy;
  it requires workspace-local allowance, explicit approval for user/system
  install, integrity, publisher and license checks, and a bounded unique
  `forbiddenMutations` list that includes protections for system PATH,
  registry, services, and raw credential storage.

Profile invariants beyond T7:

- `writableBoundaries` is non-empty, bounded, unique, secret-safe, rejects
  traversal/control/shell fragments, and may contain only the literal
  `${WORKSPACE_ROOT}` in this tranche;
- `credentialBindings` is bounded/unique and contains safe reference IDs only;
- policy and profile objects are strict closed shapes with no unknown,
  symbol, accessor, Proxy, sparse, Array-subclass, or prototype-polluted input;
- caller data is never mutated or echoed on rejection.

Result:

- immutable deterministic result with `status` equal to
  `VALIDATED_POLICY_EVIDENCE` or `REJECTED`;
- on acceptance: selected profile ID, policy ID, network mode, TTL, normalized
  install preferences, writable boundaries, credential binding refs,
  max repair rounds, stable empty issues, and accepted T7 selection evidence;
- on rejection: safe fallback identities, empty projections, sorted bounded
  issues, and no untrusted values echoed in messages;
- always: `authorityStatus: 'EVIDENCE_ONLY'` plus literal false fields for
  `profileMaterialized`, `policyPersisted`, `workspaceInitialized`,
  `environmentReadAuthorized`, `installationAuthorized`,
  `executionAuthorized`, `acquisitionAuthorized`, `mutationAuthorized`,
  `networkAuthorized`, and `taskAuthorityGranted`.
