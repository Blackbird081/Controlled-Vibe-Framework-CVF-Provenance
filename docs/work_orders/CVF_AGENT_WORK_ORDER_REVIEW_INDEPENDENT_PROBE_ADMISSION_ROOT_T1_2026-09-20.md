## Integrated Root Contract Requirements

1. Create one internal declaration-scanning API used by dispatch, linkage,
   closure and status parsing. It must apply identical masking and cardinality
   semantics before value interpretation.
2. Recognize Markdown fenced blocks opened by at least three backticks or
   tildes, with matching delimiter character and sufficient closing length.
   Fenced content, blockquotes, tables, inline-code examples and HTML comments
   cannot create declarations.
3. Every controlled scalar is exactly zero/one or exactly one as its phase
   requires. Duplicate equal values and empty duplicates fail closed.
4. Resolve exactly one link declaration across the two supported link field
   names. The referenced work order must itself have exactly one authoritative
   non-empty probe-requirement declaration.
5. Add one canonical repo-relative path validator. Reject URI schemes,
   absolute/UNC/drive paths, backslashes, empty/dot/dot-dot segments,
   repeated separators and paths outside the repository. Require referenced
   evidence files to exist and be regular files at review time.
6. Cryptographically bind closure evidence: recompute SHA-256 over the exact
   bytes at each evidence reference and require equality with its declared
   digest. The closure document cannot cite itself as either evidence file.
7. Replace free-form worker detection with exact structural identity fields:
   require a controlled non-worker role token plus distinct normalized
   implementation/probe actor IDs and invocation IDs. Free prose remains
   semantic evidence, never the machine identity oracle.
8. Encode equivalence classes as parameterized tests, including delimiter
   length, case, whitespace, duplicate order, empty duplicate, URI/path forms,
   actor aliases, missing files, digest mismatch and positive controls.
9. Preserve forward-only behavior. The three parked artifacts may remain
   reported as known compatibility findings, but must not prevent unrelated
   dispatcher commits; implement an explicit changed-lane boundary rather
   than filename-specific exemptions.
