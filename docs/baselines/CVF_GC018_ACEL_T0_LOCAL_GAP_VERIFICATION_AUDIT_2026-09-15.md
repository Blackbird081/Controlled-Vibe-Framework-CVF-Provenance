## Decision / Baseline / Proposed Tranche

The prior three-repository pilot is terminally accounted. The operator has now
selected a different external synthesis for evaluation using the same
external-to-Local method. The handoff supplies six falsifiable questions but
does not supply the canonical Lab artifacts, exact upstream repository list,
immutable source pins or license ledger. Therefore this tranche admits exactly
one Local CVF gap-verification child task while keeping multi-repository source
absorption and all experiments blocked.

The worker must classify G1-G6 as `NO_CHANGE`, `ADAPT`, `ADOPT`, `WATCH`, or
`REJECT` from current repository evidence. `ADOPT` has the highest burden and
requires proof that no current owner can absorb the responsibility.
