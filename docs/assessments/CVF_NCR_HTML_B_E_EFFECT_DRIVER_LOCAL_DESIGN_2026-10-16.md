## Counter And Native Delegation Contract

1. A nonblocking process-local single-invocation guard owns scoped substitution
   of runner PR.Protocol, E.Collector and Native bindings. Restore all originals
   in finally. Refuse nested/concurrent invocations; no cross-process lock claim.
2. FencedNative._spawn establishes a thread-local frame and calls the original
   Native._spawn exactly once. Utility frames take Collector.current_op();
   direct-launch frames observe only their successful original Protocol.grant.
   Failed grants clear frame state. No replacement queue/grant/clock is allowed.
3. The injected Popen boundary requires the exact Native/Collector/Protocol,
   exact registered op by object identity, DISPATCHED state and active frame.
   An unrelated thread, stale/nested frame or another grant cannot supply it.
4. Precharge under a counter lock before original Popen. op.cleanup selects
   work56 or cleanup8; attempt57 or9 is refused. Failed/ambiguous attempts spend
   their slot. Counters never refund, transfer partitions or reset on phase.
5. Persist a secret-safe attempt record, release counter lock, freshly check
   the same op through its original protocol and then delegate once. Persistence
   failure/expiry refuses Popen while retaining the spent slot. Never hold the
   parent protocol lock across file I/O or an adapter invocation.
6. Preserve suspended creation, Job assignment/readback, creation identity,
   existing process-root persistence, fresh resume check and retained-handle
   cleanup/finalizer/ACK. Do not copy that algorithm into the adjunct.

Counter meaning: cumulative controlled Native root Popen attempts per run,
including utility children. It is not a total OS descendant-start ledger.
Job32 is a separate concurrent-membership containment limit. Browser/Next
descendants and in-container processes are not falsely added to the root cap.
