## Decision

CADP was exposed to the same provenance blind spot at intake: its 140-file
local pack was called secondary evidence because it had no upstream URL. That
classification is incomplete under the new SOT. The pack is an operator-agent
designed, CVF-derived candidate and should have been recorded as such.

The defect did not materially suppress CADP's accepted foundational result.
Independent review converted its value into T1 contracts, T2 owner/evidence
bindings, T3A/T3B consumers, T4 checker proof, T5 adapter/authentication
foundations, and bounded T6 live evidence. The roadmap explicitly preserves
the distinction between foundational value and external runtime expansion.

T5-R6's `CLOSED_STOP_LOW_VALUE` remains valid only for the optional external
readout runtime seam at the 2026-08-15 repository state. It was based on direct
current-source searches, literal-false authorization, missing metadata and
receipt owners, and a negative value/cost margin--not on the local pack's
maturity. It must not be generalized into "CADP has low value."
